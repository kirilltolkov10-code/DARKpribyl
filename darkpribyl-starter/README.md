# DARKприбыль — Telegram Mini App starter

Нейтральный финансовый журнал: доходы, расходы, расчёт разницы и история операций.
Приложение не содержит специализированного учёта товаров или товарного ассортимента.

## Что уже подготовлено

- Тёмный интерфейс с зелёными акцентами и валютой ₽.
- Добавление доходов и расходов.
- Автоматический расчёт финансового результата.
- Сохранение операций в PostgreSQL.
- Привязка записей к Telegram ID.
- Проверка подписи Telegram `initData` на сервере.
- Удаление только собственных операций.

## Что понадобится от владельца

1. Создать бота через [@BotFather](https://t.me/BotFather) и получить токен.
2. Создать PostgreSQL базу данных.
3. Разместить приложение на хостинге с HTTPS.
4. Указать HTTPS URL Mini App в настройках бота.

## Запуск на сервере

Требуется Node.js 20+ и PostgreSQL.

```bash
npm install
cp .env.example .env
```

Заполните `.env` реальным токеном бота и строкой подключения к PostgreSQL.
Не публикуйте `.env`, токен бота или строку подключения.

Создайте таблицу в своей базе:

```bash
psql "$DATABASE_URL" -f schema.sql
```

Соберите клиент и запустите сервер:

```bash
npm run build
npm start
```

Приложение будет слушать порт `3000` (или значение `PORT`).

## Подключение к Telegram

1. Откройте `@BotFather` и выберите своего бота.
2. Настройте Mini App / Main App и задайте публичный HTTPS URL приложения.
3. Включите кнопку меню Web App, если используете её для запуска Mini App.
4. Откройте бота в Telegram и запустите приложение через его кнопку.

Для кнопки меню можно использовать Telegram Bot API `setChatMenuButton` с `web_app` кнопкой. Токен используйте только на сервере или в защищённом интерфейсе BotFather — никогда не помещайте его в клиентский JavaScript.

## Важные замечания перед реальным использованием

- Этот проект — стартовый шаблон, а не уже опубликованный сайт.
- Для production настройте HTTPS, резервные копии базы, лимиты запросов и мониторинг.
- `initData` проверяется на сервере; не используйте `initDataUnsafe` как доказательство личности.
- Удаление операции необратимо в этой базовой версии.
- Не добавляйте секреты в Git и не отправляйте токен бота в чат.
